# Span APIs developer reference

A static developer page describing the implemented Splunk Observability Cloud span metrics and span analytics APIs, with cURL examples and cross-platform integration notes.

## Publish

The `github-pages.yml` workflow deploys the `site/` directory to GitHub Pages when changes are pushed to `main`. The page is public so it can be shared by URL.

## Source

The HTML is self-contained in `site/index.html`; it has no runtime dependencies or build step.
